# E-Commerce Sales Dashboard 📊

An end-to-end data analytics and visualization pipeline that aggregates over 500,000 transaction records to feed a centralized PowerBI data model, reducing weekly reporting time by 5 hours.

## 🚀 Overview
This project demonstrates a full-stack data analytics workflow:
1. **Data Extraction & Transformation (ETL)**: Python/Pandas scripts to clean and aggregate raw transaction logs.
2. **Data Modeling**: Centralized SQL warehouse for optimized querying.
3. **Visualization**: A comprehensive PowerBI dashboard tracking Revenue, Profit Margin, and YoY Growth across global regions.

## 📈 Key Performance Indicators (KPIs)
- **Total Revenue & Profit Margin**: Real-time tracking across product categories.
- **Geospatial Sales Distribution**: Interactive heatmaps of sales across different states and regions.
- **Customer Segmentation**: Cohort analysis and Lifetime Value (LTV) estimates.

## 🛠️ Technology Stack
- **Languages**: Python, SQL (T-SQL)
- **Libraries**: Pandas, NumPy, SQLAlchemy
- **Visualization**: PowerBI
- **Database**: PostgreSQL / SQL Server

## 📁 Repository Structure
- `/sql/`: Contains the DDL and DML scripts for creating the data warehouse schema and views.
- `/etl/`: Python scripts for cleaning the raw `.csv` data and loading it into the SQL database.
- `/powerbi/`: The `.pbix` PowerBI template (requires PowerBI Desktop).

## ⚡ Results
- Successfully processed **500K+ rows** of transactional data without performance degradation.
- Automated the weekly sales reporting process, saving approximately **5 hours per week**.
- Discovered a 12% drop in regional margins due to shipping inefficiencies, leading to a revised logistics strategy.
